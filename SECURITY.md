# Security policy

Mantle is pre-release and does not yet have a supported production version.

Do not open a public issue for a suspected vulnerability, credential exposure, unsafe native behavior, dependency compromise, or resource-exhaustion flaw. Use the repository host's private security-advisory mechanism. Include a minimal reproduction, affected revision/platform, impact, and any known mitigation. Do not include real credentials, cookies, tokens, or signed media URLs.

Security fixes require a regression test when safe to retain. Mantle will not reproduce a known vulnerability or unbounded resource behavior for compatibility. Dependency advisories, license checks, provenance review, and an SBOM are release gates.
